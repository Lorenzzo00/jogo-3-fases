# Jogo de 3 Fases

## Integrantes
- Nome da pessoa 1
- Nome da pessoa 2

## Sobre o projeto
Jogo de 3 fases para testar seus conhecimentos

O jogo possui 3 fases:

1. Pedra, papel e tesoura.
2. Perguntas e respostas sobre Java
3. Perguntas de conhecimentos gerais

## Objetivo
Conseguir passar pelas três fases e alcançar a maior pontuação

## Linguagem utilizada
Java
